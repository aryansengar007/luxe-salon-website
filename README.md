## 💅 About The Project

A **modern, multi-page luxury salon website** built with **HTML5** and **Tailwind CSS** — delivering a premium, mobile-first user experience across 6 fully responsive pages. Powered by npm scripts for fast development and a clean production build workflow.

> 🌸 Developed as a portfolio and learning initiative — blending elegant UI design with a scalable Tailwind CSS architecture.

<br/>

<div align="center">

| 🎨 Styling | 📄 Pages | 📱 Responsive | 🚀 Build |
|:---:|:---:|:---:|:---:|
| Tailwind CSS utility-first | 6 fully built HTML pages | Mobile-first breakpoints | npm scripts + production CSS |

</div>

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/aryansengar007/luxe-salon-website.git
cd luxe-salon-website
```

**2. Install dependencies**

```bash
npm install
# or
yarn install
```

**3. Start the development server**

```bash
npm run dev
# or
yarn dev
```

> ✅ Tailwind CSS will compile automatically on file changes.

<br/>

## 📦 Build for Production

Compile and minify Tailwind CSS for deployment:

```bash
npm run build:css
# or
yarn build:css
```

> ✅ Outputs an optimised `main.css` with only the used Tailwind classes — significantly smaller file size.

## 🧩 Customization

To customize colors, fonts, spacing, or extend the design system, edit `tailwind.config.js`:

```js
// tailwind.config.js
module.exports = {
  content: ["./**/*.html"],
  theme: {
    extend: {
      // Add your custom colors, fonts, or spacing here
    },
  },
  plugins: [],
};
```
